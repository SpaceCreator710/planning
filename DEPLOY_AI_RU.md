# Как подключить AI через Groq

## Основной способ — один серверный ключ

1. Загрузи в Netlify архив **SOURCE**. После распаковки `package.json` должен лежать сразу в корне репозитория.
2. Открой `Site configuration → Environment variables`.
3. Добавь две переменные:

```text
GROQ_API_KEY=твой_секретный_ключ
GROQ_MODEL=openai/gpt-oss-120b
```

4. Запусти новый deploy.
5. В приложении открой `Me → AI connection → Check server`.

Так ключ хранится только в Netlify, а сайт обращается к `/api/ai`. Не добавляй ключ в `EXPO_PUBLIC_*`, JavaScript, `app.json` или ZIP: оттуда его сможет прочитать любой пользователь.

Пользователь приложения ничего не вставляет: запросы идут через защищённую Netlify Function. Если проверка показывает 401/403 — серверный ключ отклонён. 429 означает лимит Groq. При 404 выбранная модель недоступна.
