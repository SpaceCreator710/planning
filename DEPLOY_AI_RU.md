# Как подключить DeepSeek V4 Flash через OpenRouter

## Основной способ — один серверный ключ

1. Загрузи в Netlify архив **SOURCE**. После распаковки `package.json` должен лежать сразу в корне репозитория.
2. Открой `Site configuration → Environment variables`.
3. Добавь две переменные:

```text
OPENROUTER_API_KEY=твой_секретный_ключ
OPENROUTER_MODEL=deepseek/deepseek-v4-flash:free
```

4. Запусти новый deploy.
5. В приложении открой `Me → AI connection → Check server`.

Так ключ хранится только в Netlify, а сайт обращается к `/api/ai`. Не добавляй ключ в `EXPO_PUBLIC_*`, JavaScript, `app.json` или ZIP: оттуда его сможет прочитать любой пользователь.

## Быстрый приватный тест

Открой `Me → AI connection`, вставь личный ключ и нажми `Test & save`. На iPhone он попадёт в Keychain; в Web хранится только до закрытия сессии браузера. Этот режим нужен для теста, а не для публичного релиза.

Если тест показывает 401/403 — ключ отклонён. 429 означает лимит или занятость бесплатного маршрута. При 404 бесплатная модель временно недоступна. Для стабильного публичного запуска нужен резервный платный маршрут.
