# Приёмка RELEASE 12 на Mac и iPhone

Все пункты ниже ещё требуют выполнения. Linux-проверки не заменяют этот список.

1. [ ] Собрать Release всех трёх целей. Проверить, что More показывает 1.0.0 (12).
2. [ ] На узком экране и с крупным текстом открыть оба режима, размытый выбор и закрытие по фону/VoiceOver Escape. Верхние и нижние панели не перекрывают элементы.
3. [ ] Today: текущая задача наверху, ручная галочка, Add, Day Path, drag с точным временем, Undo. Соседнее задание сохраняет время. Проверить Day/Week и оба оставшихся layout.
4. [ ] Для каждой группы Intelligence применить действие и Undo; проверить результат, пустое расписание, фиксированные события и отсутствие самопроизвольного сдвига.
5. [ ] Plan Builder и Reality Replan: просмотр → Back ничего не меняет; Apply сохраняет просмотренный план; изменение расписания во время запроса не перезаписывается устаревшим черновиком.
6. [ ] Calendar: Week/Month/Year, неделя на границе месяца/года, локальное начало недели, переход даты, выбранный день и добавление. Подключение Calendar, отказ и повторное разрешение.
7. [ ] Workspace: профиль/аватар, pinned/recent, проекты, текущие задачи; каждый тип результата поиска открывается; создание/редактирование/сохранение страниц, записей, проектов, форм, Canvas и шаблонов.
8. [ ] Page AI: редактирование → запрос → review → Apply → Save. Принятый текст остаётся после повторного открытия. Проверить Reject, Undo и таймаут.
9. [ ] Автоматизация: создать → изменить → выключить → Run недоступен → включить → Run → проверить результат и Undo.
10. [ ] Inbox: дата и время → Add → Undo. Notes: Save, Share, Cancel с изменениями, черновик задачи; Goals: этапы, архив и восстановление; Memory: переключение после удаления соседней записи.
11. [ ] Обзор прошедшего дня не меняет сегодняшний. Progress открывает выбранную запись и историю. Horizon: действие открывает редактор, Cancel не создаёт задачу.
12. [ ] Focus: выбор задачи, пауза/продолжение/сброс, фон, возврат, несколько раундов, Live Activity.
13. [ ] Health/Fitness: реальная выдача разрешений, пустые и частично разрешённые данные, кольца, поиск метрик, переключатель всех метрик, поиск истории тренировок. Health AI выключен → данные не попадают в AI.
14. [ ] Все шесть разделов Settings, поиск, светлая/тёмная тема, HSL, шрифт, Reduce Motion/Transparency, haptics. Звонких звуков нажатия нет.
15. [ ] Перезапуск/обновление с RELEASE 11 сохраняет данные. Импорт/экспорт, iCloud/Supabase, две одновременные правки на разных устройствах, действия виджета/Share Extension.
16. [ ] StoreKit Release: реальные локальные цены, недоступные продукты, отмена/ожидание/ошибка покупки, восстановление без покупки и с покупкой, истечение Pro. Вход/выход и удаление аккаунта.
